在网页中精准过滤元素

Element Filter 是一款轻量 Chrome 扩展，通过 CSS 选择器或关键词，在任意网页上高亮、隐藏或仅显示目标元素——无需写代码，点开即用。

下载 Chrome 扩展 安装说明

下载 ZIP 后解压，在 chrome://extensions/ 开启开发者模式，选择「加载已解压的扩展程序」即可安装。

核心功能

面向日常浏览、调试和去干扰场景，快速定位或屏蔽页面元素。

🎯

CSS 选择器

支持标准 CSS 选择器，如 div.ad、.banner、#sidebar，精确匹配 DOM 元素。

🔤

关键词过滤

可单独使用或与选择器组合。匹配元素的文本内容及其 HTML 属性值，进一步缩小范围。

🎨

三种过滤模式

高亮标记、直接隐藏，或「仅显示」匹配项——灵活应对不同使用场景。

⚡

DOM 变化监听

开启后，页面动态加载的新内容会自动重新过滤，适合 SPA 和无限滚动页面。

🌐

Shadow DOM 支持

自动遍历 Shadow Root，在 Web Components 构建的页面中同样生效。

☁️

配置云同步

过滤规则保存在 Chrome 同步存储中，登录同一 Google 账号的设备可共享配置。

三种模式

根据需求选择最合适的过滤方式。

高亮

为匹配元素添加橙色轮廓和半透明背景，便于快速定位。

mode: highlight

隐藏

将匹配元素从视图中移除（display: none），清爽浏览。

mode: hide

仅显示

保留匹配项，隐藏同选择器范围内的其他元素。适合「只留这一条」的场景。

mode: show

效果示意

安装说明

本扩展提供 ZIP 包直接下载，无需 Chrome 网上应用店。

  1. 1

    下载扩展包

    点击页面上方「下载 Chrome 扩展」，保存 elementFilter.zip 到本地。

  2. 2

    解压文件

    将 ZIP 解压到一个固定目录，确保解压后的文件夹内包含 manifest.json。

  3. 3

    加载扩展

    打开 chrome://extensions/，开启右上角「开发者模式」，点击「加载已解压的扩展程序」，选择刚解压的文件夹。

如何使用

安装完成后，四步即可在当前页面应用过滤规则。

  1. 1

    打开目标网页

    访问需要过滤的任意网站，点击浏览器工具栏中的 Element Filter 图标。

  2. 2

    填写规则

    输入 CSS 选择器（如 div.ad）和/或关键词，选择过滤模式。需要处理动态内容时，可勾选「监听 DOM 变化」。

  3. 3

    启用并应用

    勾选「启用过滤」，点击「应用」。弹窗底部会显示匹配数量。

  4. 4

    清除或更新

    点击「清除」可一键恢复页面。扩展更新时，重新下载 ZIP、解压并覆盖原目录，然后在 chrome://extensions/ 点击刷新按钮。

隐私说明

Element Filter 尊重您的隐私，所有数据处理均在本地完成：

  • 过滤规则（选择器、关键词、模式等）仅存储在浏览器本地的 chrome.storage.sync 中。
  • 扩展不会收集、上传或分享您的浏览数据。
  • 内容脚本仅在您主动启用过滤时修改当前页面的 DOM 样式，不会向任何外部服务器发送请求。
  • 所需权限说明：storage（保存配置）、activeTab / scripting（在当前页应用规则）、webNavigation（跨 iframe 帧通信）。
